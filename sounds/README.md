# أصوات حقيقية (اختياري)

اللعبة بتولّد كل أصواتها بالكود. لو عايز تسجيلات حقيقية، حط الملفات دي هنا وهي هتتستخدم لوحدها:

| الملف | بيتسمع فين |
|---|---|
| `engine.ogg` | محرك عربيتك (loop — سرعته بتتغير مع السرعة) |
| `horn.ogg` | الكلاكس بتاعك |
| `radio.ogg` | الراديو اللي في التوكتوك (loop) |

- الصيغة: `.ogg` أو `.mp3` (غيّر الامتداد في `audio.service.ts` لو mp3).
- خلي الـloop نضيف (أوله زي آخره) عشان ميتسمعش قطع.
- استخدم تسجيلات ليك حقوقها.
